# Eduard E. Ramos - Personal Portfolio

A modern, responsive personal portfolio website for Eduard E. Ramos, an IT student and aspiring web developer.

The website uses a dark navy background with blue accents and includes Home, About, Skills, Projects, and Contact sections.

## About

I am Eduard E. Ramos, an IT student and aspiring web developer. I enjoy creating websites and web applications that are simple, functional, responsive, visually appealing, and easy to use. I am continuously learning new technologies and improving my development skills.

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Active navigation while scrolling
- About, skills, projects, and contact sections

## Setup

1. Keep `index.html`, `style.css`, and `scripts.js` in the same folder.
2. Create an `images` folder beside them.
3. Add your profile photo and project screenshots using the filenames shown above.
4. Open `index.html` in a browser, or deploy the folder to a static hosting service.

## Customize

- Replace the sample project images in `images/` with your own screenshots.
- Update GitHub, LinkedIn, Facebook, and email links in `index.html` with your actual accounts.
- Update the email recipient in `scripts.js` if your contact email changes.
- Projects marked as a proposal or idea should remain labeled that way until they are implemented.

## Contact Form Note

The contact form uses a `mailto:` link. When a visitor submits it, their default email application opens with the message prepared. The form does not send email directly from the website.
